# Todo App made with Django, React, and Postgres

This is a basic todo app currently following the tutorial at https://www.digitalocean.com/community/tutorials/build-a-to-do-application-using-django-and-react.

Tools used:

* Django
* gitignore.io
* Jest
* Postgres (tba)
* Pre-commit (tba)
* Pytest
* React
